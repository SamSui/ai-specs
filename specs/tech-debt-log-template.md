## 级别定义

| 级别 | 含义 | 处理时限 |
|------|------|----------|
| **P0** | 阻塞当前迭代，必须立即修复 | 当前 Sprint |
| **P1** | 影响功能质量，强烈建议修复 | 下轮 Sprint |
| **P2** | 有改进空间，可延后处理 | 后续迭代 |
| **Low** | 细节优化，不影响功能 | 按需处理 |

## 状态定义

| 状态 | 含义 |
|------|------|
| **待修复** | 已确认问题，有修复计划 |
| **待承接** | 已识别，等待分配责任人 |
| **暂不处理** | 已评估，当前迭代不处理 |
| **已修复** | 问题已解决并验证 |
| **已接受** | 团队接受该债务，不计划修复 |
| **已迁移** | 债务转移到未来规划 |

---

## 债务编号规则

- **TD-{NNN}**: 当前迭代产生的活跃债务
- **TD-FUTURE-{NNN}**: 已识别但计划到后续阶段处理的债务
- 编号全局连续，关闭后不回收
