# 功能清单（INVENTORY）模板

## 四级目录结构

```markdown
# {项目名称} — 功能清单（四级目录）

**文档状态**: v{digit}.{digit}
**创建日期**: {YYYY-MM-DD}
**来源**: {PRD/标书/用户故事}

---

# {模块序号} {模块名称}

## {子模块序号} {子模块名称}

### {功能点序号} {功能点名称}

**做什么:**
- {简要描述，规范要求实现的功能，≤200字}
- {功能指标，可验收标准}

**不做什么:**
- {明确边界，不在此功能范围内的事项}

**功能指标:**
- {可量化、可验收的标准}
- {引用来源：标书X.X.X}

**技术指标:**
- {性能要求、规模限制}
- {引用来源：标书X.X.X}

**技术实现占位（抽象化）:**
- 后端：`{backend_path}`（如 `{backend_path}/controller/TaskController.java`）
- 前端：`{frontend_path}`（如 `{frontend_path}/views/TaskList.vue`）
- 算法：`{algo_path}`（如 `{algo_path}/registry.json`）

**核查维度要求:**
- [ ] BE（后端API）
- [ ] FE（前端界面）
- [ ] AL（算法服务）
```

## 量化校准准则

| 维度 | 标准 |
|------|------|
| 原子性 | 一个功能点 = 一个HTTP API端点 / 前端页面 / 算法注册项 |
| 用户可见性 | 可从界面或API文档直接感知 |
| 可独立性 | 可在不依赖其他功能点的情况下单独测试验收 |
| 规模上限 | 规范描述≤200字（超过→拆分） |
| 规模下限 | 至少2个验收标准（少于→合并） |

## 示例条目

```markdown
### 3.2.1 字段完整性检测

**做什么:**
- 对结构化数据（CSV/Parquet/JSON）的指定字段执行非空检测
- 支持按比例阈值配置（默认≥95%非空）

**不做什么:**
- 不执行跨数据集的字段关联校验（属于模块6范围）
- 不自动填充缺失值（仅检测和报告）

**功能指标:**
- 支持字段级非空率检测，准确率≥99%（标书3.2.1）
- 支持阈值可配置，范围50%-100%（标书3.2.1）

**技术指标:**
- 单次检测最大行数：100万行（Phase1）
- 检测延迟≤5秒/百万行

**技术实现占位:**
- 后端：`{backend_path}/quality/FieldValidator.java`
- 前端：`{frontend_path}/views/DataQuality.vue`
- 算法：`{algo_path}/validators/completeness.py`

**核查维度要求:**
- [x] BE（后端API）
- [ ] FE（前端界面）
- [x] AL（算法服务）
```
