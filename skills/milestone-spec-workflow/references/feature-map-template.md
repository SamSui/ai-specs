# 功能地图（MAP）模板

## 模块级总览（ASCII热力图）

```markdown
# {项目名称} — 功能地图

**文档状态**: v{digit}.{digit}
**创建日期**: {YYYY-MM-DD}

---

## 功能地图总览

```
模块1: ████████░░  {XX}%  [{模块名称}]    ← {标注}
模块2: ██████░░░░  {XX}%  [{模块名称}]
...

P0问题分布: 模块{N}（{N}项）> 模块{N}（{N}项）
FDI: {X.XX}  |  FIF: {XX}%
```
```

## 分层下钻视图

```markdown
层级1：模块级总览（最多8个模块）
  [模块1]██████░░░░ 60%  → 点击进入层级2

层级2：子模块级详情
  模块{N}-{模块名称}
  ├─ 子模块{N}.1 {名称}    ████████░░ 80%
  ├─ 子模块{N}.2 {名称}    ████░░░░░░ 40%
  └─ 子模块{N}.3 {名称}    ███████░░░ 70%

层级3：功能点级详情
  子模块{N}.1-{功能点}
  ├─ FP-{ID}  {名称}    🟢存在
  ├─ FP-{ID}  {名称}    🟡弱化（路径错误）
  └─ FP-{ID}  {名称}    🔴缺失
```

## 优先级热力图

```markdown
## 优先级热力图

修复优先级矩阵（按 严重度 × 实现可独立性 排序）:

1. P0 + BE↔AL断链    → [模块{N}] {问题简述}   → 立即修复
2. P0 + FE↔BE断链    → [模块{N}] {问题简述}   → 立即修复
3. P1 + 单层缺失     → [模块{N}] {问题简述}   → 本周修复
4. P2 + 字段不全      → [模块{N}] {问题简述}   → 迭代Sprint
```
